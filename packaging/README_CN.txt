A股行情客户端 使用说明
========================

系统要求
--------
1. Windows 10 或 Windows 11，64 位系统。
2. 可正常访问程序所使用的公开行情接口。
3. 程序为便携版，无需安装额外运行库。

启动方法
--------
1. 将压缩包完整解压到具有读写权限的目录，例如 D:\Apps\AShareTicker。
2. 双击 AShareTicker.exe 启动客户端。
3. 不要直接在压缩包内运行，也不要放入 Program Files 等普通用户无写入权限的目录。

数据与隐私
----------
程序会在 AShareTicker.exe 所在目录保存自选、持仓、成交、策略配置、回放缓存和运行日志。
发布包不包含开发机器上的账户、持仓、成交、日志或历史回放数据。
升级前建议备份程序目录中的 txt、tsv 文件以及 replay_cache 目录。

行情说明
--------
当前版本使用公开 Web 行情接口，可能受网络状态、接口限流、字段调整或授权范围影响。
策略信号和回测结果仅用于技术研究，不构成投资建议，也不保证未来收益。

完整性校验
----------
SHA256SUMS.txt 记录 AShareTicker.exe 的 SHA-256，可使用以下命令核对：

    Get-FileHash .\AShareTicker.exe -Algorithm SHA256

若校验值与 SHA256SUMS.txt 不一致，请不要运行该文件。

问题排查
--------
程序运行日志保存在 logs\ashare_YYYYMMDD.log。
反馈问题时请附上发生时间、证券代码、操作步骤和对应日志，但请先检查其中是否含有不希望共享的数据。
